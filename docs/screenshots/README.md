# Screenshots

The committed screenshots show the application UI in a neutral state. They were
captured from the app with the built-in profiles (DSP Studio / parametric EQ) and
the empty-library view; they contain no third-party album artwork or personal
library metadata.

To produce release screenshots with a populated library, import the synthetic
fixtures from `Tests/Fixtures/Library` (generated by `scripts/make-fixtures.sh`)
into a fresh app-data directory. Do not publish screenshots of a real music
library.
